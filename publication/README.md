# AIFC Publication Handoff

The current repository is ready for public technical communication about AIFC as an active research protocol, subject to the exact claim ceiling in [`docs/PUBLICATION_READY_STATUS.md`](../docs/PUBLICATION_READY_STATUS.md).

This directory does not declare AIFC v1.0 frozen. It marks the boundary between completed internal scientific-assurance work and work that must be external or independently implemented.

```text

AIFC_ARTICLE_PUBLICATION_READINESS = READY_WITH_EXPLICIT_DRAFT_AND_CLAIM_CEILING
AIFC_V1_FROZEN = FALSE
EXTERNAL_PUBLIC_RANDOMNESS_BENCH = NOT_ESTABLISHED

GLOBAL_NOVELTY = NOT_ESTABLISHED
PHYSICAL_RETROCAUSALITY = NOT_OBSERVED
NEXT_PHASE = PUBLIC_COMMUNICATION_AND_EXTERNAL_FALSIFICATION
```

The article should describe the protocol, the fail-closed evidence model, the exact-main replay discipline, and the SAL v1.16 non-self-ratification boundary. It should invite counterexamples, earlier equivalent protocols, independent implementations, and external bench work rather than asking readers to accept a novelty or retrocausality claim.
